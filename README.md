# 负日者 2.0

提供浏览器在线试玩与 Windows 64 位下载两个入口。以 1.0.13 当前路演版为玩法基线，继续保留现有美术、特效、音效、九塔探索与最终 Boss 战。

## 当前机制

- 支持键鼠、Xbox / Switch Pro 手柄与游戏内手柄校准。
- 半充能球可弹射一次；满球可弹射三次，并辅助瞄准反射方向附近的小怪。
- 每次真实弹射后，可以再次伤害之前命中过的敌人；同一段飞行不重复扣血。
- 满球能落到已解锁岛屿时优先铺设跨海轨道，其他岛岸保留反弹。
- 持续加速每秒优先消耗 2 枚储存星屑，无储存时消耗 30 个百分点球充能。
- 保留缩小后的障碍碰撞、塔奖励屏幕边缘指引、满球拾取转存、怪物绕障与表现力增强。
- 出怪速率为原版 75%；九塔充能需求为 27 / 67 / 107；回血道具概率沿用此前翻倍设置。
- 调试模式默认关闭。

## 使用

在线试玩：在网页点击“在线试玩”后才下载和启动游戏，可查看加载进度、全屏，以及返回网页封面。建议使用电脑端 Chrome 或 Edge。手柄识别和按键映射受浏览器与驱动影响，可使用游戏内校准。

Windows：下载 `Sunbearer_2.0_Windows.zip` 并完整解压，运行 `SunbearerRoadshow.exe`；保留同目录的数据文件和 DLL。

网页与下载版都保留正常主菜单和完整游戏流程。网页主菜单的退出按钮会释放游戏并返回网页封面。

本轮仅进行静态文件检查、编译导出、打包及发布状态检查，没有进入 Play Mode、启动游戏、模拟输入、试听或进行试玩测试。最终键位、手感、浏览器表现和性能由负责人验收。
