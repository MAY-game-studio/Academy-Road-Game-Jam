# 圣甲虫 Unity 灰盒原型

使用 Unity Hub 将本目录作为项目打开（推荐 Unity 2022.3 LTS）。打开任意空场景，点击 Play；脚本会自动生成测试场。不需要下载美术或第三方插件。

操作：WASD 自由移动；按住空格自动推球、鼠标控制转向；松开发射。R 重置，F 满级球，G 在附近补星屑。

玩法：推球收集黄色星屑，球越大转向越慢。撞击红色靶子；满级球发射后留下蓝色加速轨道并最多反射三次。沿轨道跨越黑色缺口，在十秒内撞击三个青色按钮打开紫色门，抵达绿色出口。

选中运行时的 Scarab Greybox 对象可在 Inspector 调整移动、加速、转向、成长消耗、发射速度与轨道寿命。

当前范围：这是操控与机制试验，不含敌人 AI、角色受伤、Boss、存档或正式美术。星屑初始固定生成、破碎返还一半；旧飞行球存在时再次发射会结束旧球。轨道失效时缺口中的角色回到最近安全位置。

验证限制：已发现本机 Unity 编辑器并尝试批处理验证，但未产生验证日志，因此尚未确认 Unity 编译或 Play Mode 运行通过。首次打开时如项目使用新版 Input System，请在 Player 设置将 Active Input Handling 设为 Both 或 Input Manager。
